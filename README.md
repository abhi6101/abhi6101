## &nbsp;About

> A Full-Stack Developer and **Integrated MCA** student from **Indore, Madhya Pradesh**, building reliable web architectures and scalable backend services.

Specializing in **Java & Spring Boot** on the server side with stateless **JWT authentication** and **Role-Based Access Control (RBAC)**, paired with **React.js** on the frontend.

Hands-on experience shipping real-world software — from building an end-to-end **smart meal subscription system** during a 2-month internship at **Talking Crooks IT Pvt. Ltd.** to creating independent full-stack campus platforms.

Passionate about clean architecture, relational database integrity, and sharpening problem-solving fundamentals through **C++**.
